    Why is this step needed?

    When you first open an app downloaded from the internet, your Mac checks that it was made by a developer registered with Apple and reviewed by Apple (notarization). OCTO CREW isn't notarized yet, so the warning means Apple couldn't check it, not that something is wrong with the app. Once you allow it, macOS remembers and opens it normally from then on.

    If you prefer Terminal, this command opens it without the warning.

    xattr -dr com.apple.quarantine "/Applications/OCTO CREW.app"

    Then sign in

    Questions

    What does it cost?

    The app is free. Bots use your own Claude subscription (Pro or Max) or an Anthropic API key, and optionally your ChatGPT subscription, so usage counts against those plans.

    Why build on the SDKs instead of calling the API?

    The Claude Agent SDK and the Codex SDK already handle the agent loop, tool calls, MCP servers, permissions and subscription login. OCTO CREW adds the team, threads, routines and the Mac app around them.

    Which Macs does it run on?

    Macs with Apple silicon. Intel Macs, Windows and Linux aren't supported yet, though you can try building from source.

    Is the interface in English?

    Not yet. Labels are in Korean. Bots answer in whatever language you write to them.

    Can a bot send email or post to Slack as me?

    Not by default. "Block writes to my account apps" is on, so bots can only read from apps signed in as you. Turn it off in Settings › Computer if you want drafts you approve to go out.

    How do updates work?

    Every change merged to the main branch is built and published as a new release. The download button on this page always points to the latest one.

    Is this affiliated with Anthropic or OpenAI?

    No. OCTO CREW is an independent open-source project.
